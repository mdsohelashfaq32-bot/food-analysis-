# food-analysis-
Project Overview
The Indian Food Analysis Dashboard is an interactive data visualization project designed to analyze fast-food sales transactions and customer purchasing patterns. The dashboard provides insights into monthly transactions, popular food items, sales quantities, transaction types, and customer ordering behavior.
**Dashboard Features**
1.Key Performance Indicators (KPIs)
  Displays the total number of transactions.
  Shows the total quantity of items sold.
  Provides a quick overview of important sales metrics.
2.Monthly Transaction Analysis
  Visualizes transaction activity from January to December.
  Helps compare transaction volumes across different months.
  Identifies monthly variations in sales activity.
3.Total Quantity by Food Item
  Compares the quantities sold for items such as cold coffee, sugarcane juice, panipuri, Frankie, and sandwiches.
  Helps identify popular food items based on sales quantity.
4.Sales by Time of Day
  Analyzes sales quantities across night, afternoon, midnight, morning, and evening.
  Helps understand customer ordering patterns at different times.
5.Transaction Type Analysis
  Displays the distribution of Cash, Online, and UPI transactions.
  Helps understand customer payment preferences.
6.Transactions by Person
  Compares transaction activity associated with Mr. Sir and Mrs. Madam.
  Provides a visual comparison of the recorded transaction totals.
7.Detailed Transaction Table
  Displays individual order records.
  Includes order ID, item type, quantity, and transaction amount.
  Makes it easier to review the underlying transaction data.
8.Interactive Month Filters
  Provides month-selection buttons from January to December.
  Allows users to explore data for selected months and analyze sales trends.
**Tools and Technologies**
●Power BI: Dashboard creation and data visualization.
●Kaggle: Dataset source.
●Data Analysis: Sales trend analysis and customer purchasing pattern analysis.
●Data Visualization: Bar charts, line charts, donut charts, KPI cards, and transaction tables.
**Key Insights**
 Monthly transaction volumes vary throughout the year.
 Cold coffee, sugarcane juice, and panipuri are among the food items compared by quantity sold.
 Sales quantities differ across times of day.
 Cash, online payments, and UPI contribute to the overall transaction distribution.
 The dashboard provides a detailed view of order-level quantities and transaction amounts.
